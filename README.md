# COMP3077 - Full Stack Web Development Project

## Simple Library System (SLS)

__Made by:__ Kayden Ions

## Business Case

A library system designed to provide and manage library resources for those who need it.This systems allows for users to browse and search a catalog of books, borrow material, and search through scholarly content.

This platform also provides administrative functionality for library staff, enabling them to add, update and remove items from the database.
